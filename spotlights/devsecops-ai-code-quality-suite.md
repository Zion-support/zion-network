# 🛡️ DevSecOps & AI Code Quality Suite (Batch 78 — 2026-10-04)

Four interlinked apps covering the secure software delivery loop: **review → threat-model → evaluate → route**.

Part of the [Zion App Network](../APPS_NETWORK.md) · [Hub](../index.html) · [Status](https://zion-support.github.io/zion-status/)

## The loop

1. **[Zion AI PR Review Swarm](https://github.com/Zion-support/zion-ai-pr-review-swarm)** — multi-agent parallel code review (security, performance, style) with severity-ranked inline suggestions ([Live](https://ziontechgroup.com/zion-ai-pr-review-swarm/)).
2. **[Zion AI Threat Modeler](https://github.com/Zion-support/zion-ai-threat-modeler)** — auto-generated STRIDE threat models from architecture diagrams, CI-integrated risk flags ([Live](https://ziontechgroup.com/zion-ai-threat-modeler/)).
3. **[RAG Eval Kit](https://github.com/Zion-support/zion-rag-eval-kit)** — score retrieval quality, groundedness, citation accuracy and latency budgets of your RAG pipeline ([Live](https://ziontechgroup.com/zion-rag-eval-kit/)).
4. **[Model Router Configurator](https://github.com/Zion-support/zion-model-router)** — cost/latency/quality sliders that generate smart routing rules and fallback chains ([Live](https://ziontechgroup.com/zion-model-router/)).

## Why it matters

- **Secure every merge**: PR swarm + threat modeler gate code and design before production.
- **Trust your LLM stack**: RAG Eval Kit measures quality; Model Router optimizes cost/latency per request.
- **Compliance-ready**: exportable audit reports pair with [Zion AI Governance](https://github.com/Zion-support/zion-ai-governance) (EU AI Act readiness).
