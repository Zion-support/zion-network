# Zion App Network publication standard

Use the production five-language design and navigation patterns; do not duplicate unmaintained questionnaires or marketing claims.

## Canonical journeys
- Home: https://ziontechgroup.com/
- Free Discovery: https://ziontechgroup.com/discovery/ (en), /pt/discovery/, /es/discovery/, /fr/discovery/, /de/discovery/
- Benefits: https://ziontechgroup.com/apps/discovery-benefits.html, with /pt, /es, /fr and /de variants.
- Workflow paths: https://ziontechgroup.com/apps/discovery-workflow-paths.html, with the same locale variants.
- App Experiment Planner: https://ziontechgroup.com/apps/app-experiment-planner.html, with the same locale variants.
- App catalog: https://ziontechgroup.com/zion-app-network/

## Required page pattern
1. Correct html lang, unique title, description and canonical URL.
2. Five reciprocal language links plus x-default; do not label untranslated text as translated.
3. Shared production stylesheet, keyboard-visible focus, skip link and main landmark.
4. Clear purpose, limits and the input/output contract of every tool.
5. Home, catalog, free Discovery, source repository and relevant sibling tools.
6. Accurate availability and delivery status; never equate provider acceptance with inbox receipt or HTTP 200 with safe production functionality.
7. No invented app counts, savings, certifications, uptime guarantees or zero-risk claims.
8. Report generation must remain local when promised; actual questionnaire delivery uses its documented provider and recipients.
9. Run offline interaction/security checks and fresh deployed HTTP, release-marker and reciprocal-navigation checks.

Scope: this is a standard for ongoing consolidation, not a claim that every historical app already meets it. Legacy entry pages now point to maintained five-language canonical guides. Next audit should inventory published pages and record translation/interlink gaps by URL and locale.
